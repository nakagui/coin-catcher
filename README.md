# Coin Catcher 🪙

A **coin-catching game** developed using **Unity 6 and C#** as a personal learning project.

The goal of this project is to explore fundamental game development concepts, practice Unity features and improve my C# programming skills by building a simple game focused on collecting coins.

## 🎮 Gameplay

Collect coins as you play in a game centered around a simple objective: catching as many coins as possible. The project focuses on experimenting with core gameplay interactions and gradually improving the overall experience.

## 🛠️ Technologies

- **Unity 6**
- **C#**

## 📚 Learning Objectives

- Implement player input and movement
- Explore physics and collision detection using colliders
- Detect coin collection through gameplay interactions
- Work with object spawning and positioning
- Practice score tracking and gameplay feedback
- Create and manage simple game interfaces (UI)
- Experiment with animations and visual feedback
- Explore sound effects and audio feedback
- Improve code organization, maintainability and C# skills

## 🚀 Getting Started

1. Clone this repository.
2. Open **Unity Hub**.
3. Add the cloned project to Unity Hub.
4. Open the project using its compatible Unity 6 version.
5. Open the main scene and press **Play**.
